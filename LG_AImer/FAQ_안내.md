해커톤 운영 과정에서 운영진에 자주 들어오는 문의 목록과 답변(FAQ)을 정리하여 전달드립니다.

FAQ는 지속적으로 본 게시글에 업데이트될 예정입니다.



[외부 데이터/도메인 지식 관련]
1) 외부 데이터 활용 가능한가요?

-> 대회 규칙에 기재된 것과 같이 해커톤에서 제공되는 데이터 외에는 추가 수집이 불가능합니다. 또한 제공되는 데이터 중 학습 데이터만 모델 학습에 활용할 수 있습니다.



2) 외부 데이터와 도메인 지식의 차이가 무엇인가요? 그리고 명확한 기준을 알려주세요.

-> 관련 내용은 '외부 데이터와 도메인 지식의 차이 그리고 허용 기준' 안내 게시글 [링크]에 안내되어 있으며, 그럼에도 불구하고 사용여부가 애매하여 판단이 어려운 경우에는 데이콘 운영진에게 문의 부탁드리겠습니다.



[데이터 관련]
1) 학습 데이터의 매출 수량에 '음수'는 무엇인가요?

-> 학습 데이터에 존재하는 음수는 참가자가 직접 해석하여 모델 학습에 활용할 수 있도록 RAW 데이터 그대로를 반영해두었습니다. 이 경우에는 매출 취소, 오류 등의 여러 요인이 존재할 수 있습니다. 다만, 평가 데이터의 실제 정답(GT)에는 음수는 존재하지 않습니다.



2) 평가 데이터의 Input의 통계 정보를 활용해도 되나요?

-> 예를 들어, TEST_00 샘플을 예측할 때, TEST_00의 Input으로 주어진 데이터의 통계 정보는 활용 가능합니다. 이는 추론 시점 기준보다 과거의 데이터로 주어졌기 때문입니다. 단, TEST_00의 Input 통계 정보가 TEST_01 예측에 활용되는 것은 불가능합니다.



[모델링 관련]
1) 모델이 28일치 데이터를 입력받아서 무조건 7일치를 한번에 출력해야하나요?

-> 추론에는 최대 28일간의 입력 데이터를 자유롭게 활용할 수 있으며, 7일치를 한 번에 예측하거나 하루씩 7번 나누어 예측하는 것도 가능합니다. 다만, 예측 결과를 모델 학습에 다시 사용하는 것은 허용되지 않습니다.



2) 재귀적 예측(1일을 예측해서, 2일 예측의 1일 예측 결과를 Input으로 활용)도 가능한가요?

-> 추론에는 최대 28일간의 입력 데이터를 자유롭게 활용할 수 있으며, 예측 결과의 경우는 추론 시점 이전에서 예측된 결과로 간주되기 때문에 Input으로 활용 가능합니다.

다만, 예측 결과를 모델 학습에 사용하거나 다른 평가 샘플에 활용하는 것은 불가능합니다.
